# Sound Dunes Production Website

Production website deployment completed through Aroai in partnership with BDB Industries for Sound Dunes Production.

## Project Overview

This project involved taking an existing locally running JavaScript website and moving it into a production-ready hosted environment.

## My Contributions

- Configured Git/GitHub source control and production repository structure
- Resolved repository authentication and synchronization issues
- Configured Netlify hosting and build settings
- Set up GitHub-connected automated deployments
- Coordinated Squarespace-managed domain configuration
- Worked through DNS, HTTPS, and production deployment validation
- Tested production behavior and ongoing deployment workflow

## Technology Stack

- JavaScript
- Node.js
- Git
- GitHub
- Netlify
- Squarespace DNS
- CI/CD-style deployment workflow

## Deployment Architecture

Developer workflow:
Local development → GitHub → Netlify → Custom domain

## Key Challenges

### Repository Structure
The original project existed inside a larger repository. I separated the production website into a clean deployment repository.

### Git Authentication
Resolved HTTPS push failures by configuring GitHub SSH authentication.

### Hosting
Configured Netlify to build and publish the static site's production output.

### Domain Configuration
Connected the hosted application to a Squarespace-managed custom domain using DNS configuration.

## Outcome

The locally hosted application was converted into a production website with a repeatable Git-based deployment workflow.
